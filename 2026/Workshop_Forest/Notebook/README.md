# Oracle Machine Learning (OML) Notebook

This folder contains the **Oracle Machine Learning (OML) Notebook** used during the Forest Workshop.

The notebook includes hands-on exercises and examples designed to run in **Oracle Autonomous AI Database**.

### 1. Prerequisites

Before importing the notebook, ensure that:

- You have access to an Oracle Autonomous AI Database.
- Your database user has been created and enabled for Oracle Machine Learning (OML).
- You have the required database privileges to execute the workshop exercises.
- The OML Notebook file `FOREST_Workshop_EN.dsnb` is available.

### 2. Log in to Oracle Machine Learning

1. Open **Oracle Machine Learning (OML)** in your web browser:

   `https://<your-adb-url>/oml`

2. Log in using your database username and password.
3. Navigate to the **Notebooks** section.

### 3. Import the Workshop Notebook

1. In OML, open the **Notebooks** page.
2. Click **Import**.
3. Select the notebook file:

   `FOREST_Workshop_EN.dsnb`

4. Complete the import process.
5. Verify that the notebook appears in your notebook list.

### 4. Open and Run the Notebook

1. Open the imported notebook `FOREST_Workshop_EN`.
2. Review the notebook instructions and prerequisites.
3. Ensure that the required notebook interpreters are available.
4. Execute the notebook paragraphs in the specified order.
5. Review the results after each step before continuing.

**Note:** Some exercises may require database objects, AI profiles, OCI credentials, or additional privileges to be configured before execution.

### 5. Troubleshooting

Unable to log in to OML:  Verify that your database user is enabled for OML.
